## 📱 About

**GlucoTrack** is a cross-platform diabetes self-management application built with **Flutter and Dart**.

The application is designed to help users record and monitor their blood glucose readings through a simple, accessible interface, while providing a clear visual overview of their data over time.

GlucoTrack is an independently developed project, built and maintained from the ground up as a practical Flutter application.

---

## ✨ Features

* 🩸 **Blood Glucose Tracking**
  Record and manage blood glucose readings.

* 📊 **Data Visualization**
  View glucose data through interactive charts and visual summaries.

* 💾 **Local Data Storage**
  Store recorded readings locally for easy access and tracking.

* 🌙 **Dark & Light Mode**
  Switch between light and dark themes according to user preference.

* 🌍 **Bilingual Support**
  Supports both **English and Egyptian Arabic** for a more accessible user experience.

* 📱 **Responsive UI**
  Designed to provide a consistent experience across supported screen sizes.

* 🎨 **User-Friendly Interface**
  Clean and accessible UI focused on making health data easy to understand.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Flutter SDK
* Dart SDK
* Android Studio or another Android development environment
* Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/haneenmo28/GlucoTrack.git
```

2. Navigate to the project directory:

```bash
cd GlucoTrack
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
